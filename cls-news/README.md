# 财联社电报自动分析模块

只修改网页中隔离的财联社电报区域，不改行情、量比、成交统计、其他新闻及公告功能，不改变转发接口及30秒最新刷新间隔。

默认北京时间今天。最新20条先展示并立即规则分析，随后自动从新到旧分页补齐源站可返回的当天范围。最近三天和历史日期仍可选择。最新刷新与旧消息补齐使用独立请求队列；两次刷新之间超过一页的新消息会追加补齐，不重置历史游标；按ID去重，源文修订会重新分析。切换日期取消旧请求，默认今天视图跨午夜自动切换日期。补齐失败保留已加载内容并提示尚未完整，后续刷新会重试。

所有已取得的电报均分析，无须先选股。采用本地可解释规则，不调用大模型或新增付费API。关注分0–100不代表涨跌概率：基础8分；货币财政监管实质动作+31、跨市场大幅波动/供应风险+27、行业供需技术政策动作+24；源站重点+5；否定/传闻/拟议-22；缺正文/过短-8；风险词+5或确认倾向+3；直接股票关联+18或行业标签关联+10。总分截断至0–100。重大事件触发且总分至少24置顶；直接股票或行业标签关联则独立置顶。词义和传导关系仍可能误判，不作确定股价预测。

默认置顶优先，每组按发布时间倒序；可切换全部最新优先。每条可展开查看传导逻辑、评分分解、关联命中和原文特征。股票行业与标签只使用原网页实际取得的数据，变化后自动重评；分类不可用时不猜测行业。

只分析公开接口实际返回的标题与电报正文，不额外抓取付费或缺失全文；空正文、未补齐、数据源异常均明确提示。“所选范围已加载完”只表示已遍历接口返回的数据，不保证源站无遗漏。

## 转发服务

数据来自财联社公开网页接口 `https://www.cls.cn/v1/roll/get_roll_list`，不需要账户或密钥。`server.py`仅为只读跨域转发，与股票服务独立。运行需要Python3和requests：

```sh
python3 -m pip install requests
python3 cls-news/server.py
```

默认端口8767。接口 `/api/cls-telegraph` 支持 `date=YYYY-MM-DD` 与 `cursor=Unix秒`；`/health`为健康检查。仅允许本站和指定本地测试来源，不接收任意上游URL，不含账户和写操作。最新页缓存最多15秒，历史页最多300秒。

页面打开且可见、网络和服务正常时，每30秒检查最新电报；收到后立即规则分析。后台浏览器可能节流，关闭页面不会继续前端分析。历史日期不自动轮询。当前HTTPS转发地址属于现有云端运行环境，并非永久托管；环境休眠、服务停止、地址失效或源站限制会使更新暂停，网页会报错并保留本次已取得内容。长期无人值守需另行部署常驻HTTPS服务，本次未购买或开通新服务。

## 代码和测试

`analyzer.js`为纯规则分析器，`feed.js`为独立前端队列；为保持现有单文件网页部署，这两段代码同时内嵌在根目录index.html的隔离模块内。

```sh
node cls-news/test-analyzer.cjs
```

评分测试覆盖实质动作门槛、否定拟议语境、公司及行业别名、泛标签过滤、正文缺失和固定分解。开发环境另有mock DOM/网络队列测试，覆盖最新优先、补齐去重、跨刷新补漏、失败保留、切日隔离、股票重评及跨日。
