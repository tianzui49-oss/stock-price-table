# 财联社新闻电报独立模块

本模块仅新增页面底部的财联社电报区域，不修改现有行情、成交明细、相关新闻及公告代码。

默认范围为北京时间今天及前两天。日期选择器可查询更早日期，实际历史范围由财联社官方接口决定。每批 20 条，可继续翻页；最近三天或今日视图在页面可见时每 30 秒读取一次。历史日期不自动轮询。

数据取自财联社官方公开网页使用的 `https://www.cls.cn/v1/roll/get_roll_list`，使用网站签名规则生成请求；不需要用户账户或密钥。源接口无 CORS/JSONP，故 `server.py` 提供独立只读转发，不依赖或修改股票后端。

## 独立运行

需要 Python 3 和 requests：

```sh
python3 -m pip install requests
python3 cls-news/server.py
```

默认端口 8767。接口为 `/api/cls-telegraph`，可选 `date=YYYY-MM-DD`、`cursor=Unix秒`，健康检查为 `/health`。仅允许本站和指定本地测试来源跨域访问，不接受任意上游 URL、账户信息或写操作。当前页面连接当前云端工作环境转发的 HTTPS 地址；它不是永久托管。云端环境休眠、停止或地址失效时会暂停更新，页面显示错误并保留本次已加载数据。长期运行应将此独立服务迁至常驻 HTTPS 主机，并仅替换新增模块中的 API 常量。

缓存：最新页最多 15 秒；已结束历史日期页最多 300 秒。源站限流、内容调整、接口策略变化或网络延迟均可能影响结果。不保证零延迟或超出源站可返回范围的历史完整性。
